# TidyShot Phase 7: Optimise Images with Clop Before Upload, Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** When "Optimize images with Clop" is on and Clop is running, every upload sends the PNG Clop returns (about 65 to 73 % smaller in the probes); any failure, conversion or a result that is not smaller uploads the original.

**Architecture:** Spec section 2.7 of `docs/superpowers/specs/2026-10-19-tidyshot-screenshot-design.md` (settled 2026-10-21) is the full specification: types, names, strings, timeouts, the entitlement and the tests. A vendored MIT `ClopClient` talks to Clop's CFMessagePort; a pure `ClopOptimiser` with an injectable transport writes a throwaway copy in the container's `tmp/Clop`, lets Clop rewrite it, validates and reads it back; `AppCoordinator.startUpload` calls it, so every upload path is covered. The probe's working client is `docs/superpowers/research/clop-client-probe.swift` (compiled under TidyShot's Swift 6 settings and reached Clop from a sandboxed probe); start from it.

**Tech Stack:** Swift 6 language mode with default `MainActor` isolation and `NonisolatedNonsendingByDefault`, CoreFoundation `CFMessagePort`, Foundation `JSONEncoder`/`JSONDecoder`, ImageIO, SwiftUI Settings, Swift Testing, XcodeGen 2.46.

Work happens on branch `phase-7-clop` from `main` at d72d304.

## Global Constraints

- Every earlier constraint still applies (minimum macOS 26.0, Swift 6 MainActor default, sandbox, credentials only in the Keychain, one save, upload and delete path, KeyboardShortcuts as the only Swift package, no GPL code read or copied). The Clop app is GPLv3: never read or copy it. ClopSDK is MIT: the vendored client carries the MIT header from spec 2.7 and a `ThirdPartyNotices.md` entry with ClopSDK's licence text.
- The one entitlement change is the mach-lookup temporary exception in spec 2.7, for exactly the two port names it lists. No other entitlement changes.
- TidyShot never launches Clop. Uploads are always PNG. Optimisation never blocks the main actor; the blocking client call runs in a detached task with the spec's timeouts.
- A capture is never lost: every failure path uploads the original bytes, logs one `NSLog("%@", ...)` line starting `Clop: `, and posts no error.
- Exact strings come from spec 2.7.
- Tests use Swift Testing, run with:
  ```bash
  xcodegen generate && xcodebuild test -project TidyShot.xcodeproj -scheme TidyShot -destination 'platform=macOS' -derivedDataPath .build 2>&1 | grep -E "Test run with|error:|TEST"
  ```
  Baseline `Test run with 817 tests in 96 suites passed`. Release builds Tim runs: `xcodebuild -project TidyShot.xcodeproj -scheme TidyShot -configuration Release -derivedDataPath .build-rel build`.
- Commit after every task with a conventional message and no attribution lines; never push. The controller pushes and opens the PR after the whole-branch review.
